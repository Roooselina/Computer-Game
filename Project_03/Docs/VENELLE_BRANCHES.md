## 1. 흐름

```
C06 등장 ─▶ 실시간 전투 ─┬─ 협상 성립 (신뢰≥4, 위협≤2 로 대화 마침) ──────────────┐
                        │                                                         ▼
                        └─ 체력 0 → 쓰러짐(Downed) → 다가가 J ─┬─ 죽인다 ─▶ [사망]   VenelleEnd2: 쓰러짐 개그 → 짧은 부축 → 컷
                                                              └─ 죽이지 않는다 (신뢰 +2) ─▶ ┘          │
                                                                                                         ▼
                                                                        M15 휴게실 벤치 RestScene (경계 속 대화)
                                                                          ├─ 초콜릿 건넴 (있을 때, 1회: 신뢰 +2·위협 −1)
                                                                          ├─ 솔직한 대답 (1회: 신뢰 +1)
                                                                          └─ '출구까지만, 같이 가.' ─┬─ 신뢰 ≥ 3 ─▶ [임시 동행]
                                                                             '여기서 쉬어...' ──────┴─ 신뢰 < 3 ─▶ [따로 감]
```

## 2. 결과 상태

| 결과 | SaveData | 플래그 | 이후 |

- 진행이 막히는 조합은 없다: C06 오른쪽 출구는 `c3_boss_done` 이면 열리고, 시연 끝 이벤트도 `c3_boss_done` 만 본다.
- 저장·불러오기와 구간 재시도 뒤에도 위 상태와 `v_threat`/`v_trust`/`v_agit`, 선택 기록 `v_opt_*` 가 유지된다(재시도는 마지막 구간 시작점의 값으로).

## 3. 반응 축과 선택 (`VenelleMind`)

| 축 | 시작 | 오르는 일 | 내려가는 일 |
|---|---|---|---|
| 위협 | 5 | 루가 때림(+1), 자극(+1) | 놓아 달라·손을 내림(−2, 처음만, 최근 8초 안에 안 때렸을 때), 가까이서 12초 안 때림(−1, 최대 3), 분전함을 꺼 줌(−1), 초콜릿(−1) |
| 신뢰 | 0 | 나가려는 거야(+2), 왜 찾아(+1), 놓아 줘·손을 내림(+1), 분전함(+2), 살림(+2), 초콜릿(+2), 솔직한 대답(+1) — 모두 처음 한 번 | 빈틈(숨 고르기·재혼합)에 때림(첫 번 −1) |
| 흥분 | 4 | 자극(+2), 맞음(+1), 같은 질문 반복(+1), 신용 없는 '놓아 줘'(+1) | 왜 찾아(−1), 8초마다 −1 (2 이하로는 안 내려감) |

- 같은 말의 효과는 한 번만. 반복하면 '아까 그 말~ 기억해' 같은 기억 반응만 나온다.
- 틀린 선택은 축이 조금 나빠질 뿐 진행을 처음으로 돌리지 않는다.
- 아직 모르는 린든의 이름·베넬의 과거는 선택지에 없다.

## 4. 잡기 대화

- 처음 잡혔을 때: '자~ 잡았다아. 어디 보자...' / '놔, 놔줘...!' / '가만있어~ 데려가야 한단 말이야. 딸꾹—' → 선택 4개.
- 다시 잡혔을 때: '또 잡혔네에~?' → 같은 선택.
- 선택 결과로 협상이 성립하면 던지지 않고 내려놓는다. 아니면 던진다(착지 피해 1회 + 보호 1.3초).

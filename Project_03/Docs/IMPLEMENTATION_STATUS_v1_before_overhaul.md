## 1. 한눈에

- 타이틀 → 새 게임 → **프롤로그 → 1장 → 2장 → 3장 베넬 협상·쓰러짐·부축·휴식·동행 → 시연판 종료 안내 → 타이틀** 까지 끊김 없이 이어진다.

- 실제 Unity 6000.6.0f1 에디터에서 컴파일·구성·자동 테스트(EditMode 44, PlayMode 10 전부 통과)·Windows 빌드(성공, 실행 확인)를 했다.

## 3. GDD 대비 추가·변경한 점 (확인 필요)

1. **추가 대사**: GDD 원문에 없는 연결용 문장(조사 설명, 조작 안내, 시스템 문구, 협상 1·2단계 대사, 과자 건네기, 제압 경로 연결, 시연판 종료 안내)은 `dialogue_ko.json` 에서 줄마다 `"added": true` 로 표시했다. 협상 단계 대사는 GDD 에 없어 짧게 지었으니 검토가 필요하다.
2. **기록 D01·D03 본문**은 GDD 에 목적만 있어 짧게 작성했다 (`added: true`).
3. **맵 이동 자동 저장**: GDD 저장 지점(장 시작·안전실·보스 앞) 외에 맵 이동 때도 저장한다. 시연판 편의 기능이며 `GameConfig.autosaveOnMapEnter` 로 끈다.
4. **재시도 시 안정도 회복** (이야기 난이도 `retryHeal`): 낮은 체력으로 진 전투를 같은 체력으로 반복하는 막힘을 막기 위해 추가. 소모품·경험치 복원 규칙은 GDD 그대로.
5. **수치**: GDD 4.2 계수를 따르고, 기본 공격만으로 일반전을 이길 수 있도록(GDD 4.3) 루 기본 안정도 48, 적 체력(경비 26·드론 14·운반 28) 등을 정했다. 시뮬레이션 테스트로 예상 레벨에서 '톡!'만 써도 승률 95% 이상임을 확인했다. 실제 체감 조정은 플레이 테스트 후 `GameDatabase.asset` 에서 한다.
6. **적 그림·역할 대용**: 순찰 경비 = Droid03, 포획 드론 = Droid01, 운반 로봇 = Droid02 (GDD 13.4 "드로이드 2종부터" 범위). 2장 적재장 조합은 GDD 의 '운반 로봇 + 정비 거미' 대신 '운반 로봇 단독 / 운반 로봇 + 포획 드론'.
7. 맵 ID·이름은 GDD 5장을 따르되, 각 맵은 짧은 사이드뷰 방으로 지었다. 일반전 배치: 05(2)·07(1)·10(2)·12(2) 고정, 14 선택(1).

### 검증하지 못한 것
- 사람이 키보드로 처음부터 끝까지 플레이한 확인, **플레이 시간 실측 (20~30분은 목표치일 뿐)**. 자동 경로 테스트는 대사 자동 넘김·즉시 선택이라 시간 측정이 아니다.
- 게임패드 실제 입력, 여러 해상도·전체 화면, 오디오(이 PC 에서 FMOD 출력 장치 초기화 실패 로그가 있어 소리는 확인 불가).
- 빌드 실행본에서의 장시간 플레이·저장/이어하기 (에디터 Play Mode 에서만 자동 확인).
- 말풍선 개별 조건 14종 각각의 출력 (출력 체계와 '첫 동행'만 흐름 테스트에서 지나감).

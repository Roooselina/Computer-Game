## 3. Esc 검수 도구

Esc → ‘검수 도구’: 현재 맵 ID·이름·장·체크포인트·베넬/라비엘 상태 / 정상 진행의 다음 맵(후보·조건 표시) / 이전 방문 맵 / 전체 맵(장별) / 주요 사건 21종 프리셋(베넬 분기 선택 → 바뀌는 내용 표시 → 확인) / 현재 맵 다시 시작 / 검수 슬롯 저장·이어하기 / 검수 시작 전 상태로 복귀.
- 첫 이동 때 시작 상태를 보관하고 저장 폴더를 `<일반 저장 폴더>/review/` 로 바꾼다. 일반 저장 파일은 검수 중 쓰이지 않는다 (자동 테스트로 바이트 비교).
- 이동 전 정리 (`Game.HardReset`): 진행 중 이벤트·대화·컷신·지연 코루틴·입력 상태·시간 배율·페이드·레터박스·투사체·영상/휴지통/엔딩 창. 죽은 인물은 추종자로 생기지 않는다 (상태 기반).
- 모순 방지: 8장 이후 사건에서는 ‘동행 생존 베넬’을 고를 수 없다.
- 노출: 에디터·개발 빌드 항상, 일반 빌드는 `GameConfig.reviewToolsInRelease` (지금 켬).

## 5. 확인하지 못한 것 (정직하게)

- **사람의 손 조작·조작감·난이도·감정선**: 모든 경로는 가상 키 입력 봇과 자동 테스트다. 보스 수치는 봇이 겨우 이기는 수준을 보고 이야기 난이도 쪽으로 낮췄을 뿐, 사람이 해 본 값이 아니다.
- 소리: 새 음악·효과음을 만들지 않았다 (기존 생성 효과음 재사용). 들어 보지 않았다. 라크리모사 기믹은 소리 0 에서 통과하는 것만 테스트로 확인.
- 섬광·흔들림 감소 설정을 켠 상태로 7~11장을 보지 않았다 (위험 표시는 바닥 띠·글자로도 나오게 만들었다).
- 게임패드, 해상도별 UI, 실제 키보드 반복 입력.

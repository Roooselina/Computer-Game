### 실제 재생 중 발견해 고친 문제
- 기존 시트 분할 도구가 한 장짜리 스프라이트의 피벗을 고치지 못하던 버그(기존 객체를 직접 고쳐 '변경 없음'으로 판정) → 수정. 그 영향으로 바닥 콜라이더가 그림 피벗을 따라 올라가 루가 바닥에 갇히던 문제 → 콜라이더 오프셋 0 고정.
- 기존 플레이어 이동: 1칸 턱 모서리에 살짝 파고들면 점프가 막히던 문제 → 발밑 작은 턱은 밟고 올라서게 수정.
- 컷신을 연구원 등장 전에 건너뛰면 연구원이 문 앞에 쓰러져 있던 문제 → 완료 처리에서 쓰러진 자리로 이동.
- 마을 중경이 하늘과 같은 명도라 안 보이던 문제, 정전 어둠이 약하던 문제, 천장 조명이 화면 밖이던 문제, 전투 화면에 노출 전선이 안 들어오던 문제, 긴 맵에서 전경 기둥이 화면 가운데를 지나가던 문제, 바닥 아래 타일이 시끄럽던 문제 → 수정.
- 녹화 이후 방전 번쩍임 최대치를 0.85 → 0.6 으로 낮췄다 (녹화 영상은 0.85 상태).

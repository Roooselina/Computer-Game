### S08-1 상층 회랑 — 재회와 변신 (컷신 `c8_reunion`)
- **맵**: M32 상층 회랑 · 진입 시 `chapterId = ch8` 저장
- **등장인물**: 루, 라비엘 (사람 → 괴물 토끼)
- **실제 대사 (GDD 원문)**: 루 ‘어? 너... 잠깐, 진짜 너야? 여기서 뭐 해!’ / 라비엘 ‘넌 정말이지 변하지 않았구나.’ / 루 ‘너는 엄청 변했네! 그건... 아, 지금 그 말부터 하면 안 되나?’ / 라비엘 ‘아무렇지도 않네. 돌아오지도 않았으면서.’ / 루 ‘...돌아가려고 했어. 계속.’ → (보충) 라비엘 ‘...거짓말.’ → 변신 → ‘라비엘! 잠깐만..!?’
- **선택지 (기본 선택 없음)**: 루 ‘...다치게 하고 싶지 않아.’ → 「도망친다 — 거리를 벌린다」 / 「멈춰 세운다」 → `friendRoute = flee / fight`
- **보스 앞 저장** `c8_duel_before`. 재시도 시 `c8_route_chosen` 이면 곧바로 대결 재개.

### S08-2a 도망 경로
- 라비엘이 뒤쫓고 도약(착지 표식). 루는 회랑 끝까지 달린다. 셔터 패널을 누르면 4초간 라비엘만 막힘. 공격해도 쓰러지지 않음(잠깐 멈칫).
- 회랑 끝 → `c8_flee_end` (서술 ‘회랑 끝 문 앞. 쫓아오던 발소리가 멈춘다.’ / 루 ‘라비엘! 나 여기 있어! 안 가!’)
- **확인**: [봇](2경로) [테스트]

### S08-2b 멈춰 세우기 경로
- 라비엘 HP 34. 도약·휘두르기·돌진. 옆 문으로 돌진을 유도하면 문이 부서지고 멈칫. HP 0 → 무릎 꿇음 → `c8_fight_end` (서술 ‘괴물 토끼가 무릎을 꿇는다.’ / 루 GDD 원문 ‘그만! 나 네 얼굴 때리기 싫어!’)
- **확인**: [봇] [테스트](톡! 명중·죽이지 않음)

### S08-3 대결 뒤 (컷신 `c8_stop`)
- 변신이 풀린 라비엘 ‘...왜 도망 안 가.’ / 루 ‘도망은 했지. 너한테서가 아니라 너 다치는 거에서.’ / 라비엘 ‘......내 방. 이쪽이야.’
- **상태**: `c8_duel_done` (라비엘은 아직 동료 아님 — `ravielState none`)
- **GDD 와 다른 점**: GDD 의 ‘옆에 있는 문! 문 부숴! 나 말고!’ 는 대결 중 문이 처음 부서질 때 말풍선(‘문! 그래, 문 부숴! 나 말고!’)으로 바뀌어 있다 (정적).

### S08-4 라비엘의 방 — 사진과 고백 (컷신 `c8_confession`)
- **맵**: M33 · 액자 두 개 조사
- **실제 대사**: GDD 원문 사진 대화(‘너 이 사진 아직 갖고 있었어?’ / ‘버리려고 꺼내 놨던 거야.’ / ‘액자에 넣어서?’ / ‘......말 많아.’) → (보충) 서로 잡혀간 이야기 → GDD 원문 고백(‘널 부른 건 나야. …’ ~ 루 ‘내 친구니까. 아직도 몰라?’)
- **선택지 (기본 선택 없음, 연출만)**: 「손을 잡는다」 / 「옆에 앉는다」 → `reunionChoice hand / sit` (점수·조건 변화 없음, 테스트로 확인)
- → 라비엘 독백 GDD 원문 ‘(돌아오면 묻고 싶었다. 왜 나였냐고. 막상 돌아오니 먼저 이름을 부르고 싶었다.)’
- **상태**: **`ravielState = ally`**, 동료(라비엘) 생성, 저장
- **선택 이야기**: 깨진 컵 `c8_cups` (‘손잡이만 없잖아. 양손으로 잡으면 돼.’ + 보충) → `sideStoryDone cup`. **GDD 의 ‘이후 안전실에서 둘이 그 컵을 쓴다’ 장면은 없다** (11장 대화에서 한 줄 언급만).
- **확인**: [봇][테스트]

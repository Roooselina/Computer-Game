### S04-2 폐기소 거처 — F·008 첫 만남과 교섭
- **맵**: M17 폐기소 거처
- **진입 조건**: 입구 구역 `waste_meet`, `waste_met` 없음
- **등장인물**: 루, F, 008, 생존자 셋 (+동행 베넬)
- **사건**: 컷신 `c4_waste_meet` — 파이프를 든 사람들, 루가 손을 든다.
- **실제 대사 (GDD 원문)**: 루 ‘잠깐! 먹을 거면 나 말고 이거! 나 맛없어! 찌릿해!’ / F ‘누가 널 먹는대. 손에 든 거 내놓으란 거지.’ / 루 ‘아. 그럼 얘기가 빠르네!’ / 008 ‘얼마나 찌릿해?’ / 루 ‘그건 먹어보고 확인하는 질문 아니야!’ → (보충) F ‘위로 가는 승강기는 막혔다. 여긴 거기서 밀려 내려온 사람들이야.’ ‘물이 끊긴 지 사흘. 펌프가 멎었어.’ ‘먹을 거든 고칠 손이든. 하나는 내놓고 지나가.’
- **선택지 (기본 선택 없음)**: 「과자 10개를 나눈다 (가진 과자 N개)」(10개 미만이면 흐림·선택 불가) / 「물 펌프를 고쳐 줄게」 / 「못 줘! 그냥 지나갈게!」
- **결과**:
  | 선택 | 장면 | 상태 |
  |---|---|---|
  | 과자 10개 | `c4_gift` (F ‘...진짜로 내놓을 줄은 몰랐다.’ ‘하나씩 받아. 나눠. 애들 먼저.’) | 과자 −10, `wasteResult gift`, `waste_resolved` |
  | 펌프 | `c4_deal_pump` → M18 에서 수리하면 해결 | `waste_pump_promised` → 수리 뒤 `wasteResult repair`, `waste_resolved` |
  | 거절 | `c4_deal_fail` → 겁먹은 생존자 셋과 실시간 비살상 충돌 → 셋 모두 진정 → `c4_fight_end` (F ‘그만! 다들 그만.’) | `wasteResult fight`, `waste_resolved`. 이후 펌프를 고치면 `wasteReconciled` |
- **이후 상호작용**: F 조사 `waste_f` — 원문 이름 장면 `c4_f_name` (F ‘이거 말고 이름이 있었는데, 오래돼서.’ / 루 ‘그럼 오늘은 F 할머니! 내일 생각나면 다시 알려줘!’ / F ‘내일도 올 생각이냐.’ / 루 ‘과자 주면!’) → 빈 상자 던짐(과자 교섭이면 `c4_f_box_gift`). 008 조사 `waste_008` — 「과자를 하나 준다」/「지금은 안 준다」 → 원문 ‘하루에 하나씩 먹으면 오래 있어?’ → **동행일 때만** 베넬 ‘...하루에 하나만 먹지 마. 배고프면 더 먹어.’ → 루가 자기 과자 반 (`c4_008_split`, 없으면 `c4_008_split_none`). → `child008Fed`
- **대피실**: `shelterGroups` 에 `waste_residents`. 해치 조사 ‘대피실 — 자리 남음’.
- **코드**: `StoryEventsUnderground.cs` `WasteMeetZone` (117) · `WasteDeal` (177) · `WasteF` (242) · `Waste008` (287), 충돌 `Action/Scavenger.cs`
- **확인**: 펌프 [봇](새 게임 경로) · 과자/거절 [봇](2026-11-15 경로 B/C) · 과자 충분·부족 [테스트](`Ch46Tests`)

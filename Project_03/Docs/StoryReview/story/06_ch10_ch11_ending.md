### S10-4 최종전 3단계와 한계 방출
- 1단계 외피·호위 구(전자석) / 2단계 축전·냉각(축전 모듈·냉각 밸브) / 3단계 결합부(연결 광선·낙하물). 단계마다 HP 30. 라비엘 엄호막 7초마다.
- 단계 HP 0 → 결합부 아래 바닥에서 조사 → 전하가 가득하면 **한계 방출** 컷신(‘......하나.’ ‘둘.’ ‘셋.’). 전하가 모자라면 안내만. 방출마다 최대 안정도 −20%(최초 기준), 세 번 뒤 40%. 재시도 중복 없음.
- 메이린은 왼쪽 캡슐에서 손잡이를 당기는 인물(공격 대상 아님).
- **확인**: [봇](3경로, 1회 사망 재시도 포함) [테스트]

### S11-1 무너진 중정 — 마지막 대화 (컷신 `c11_wake`)
- **맵**: M46 (시설 안의 무너진 공간) · `chapterId = ch11`
- **실제 대사**: GDD 원문 ‘...으아. 우리 착지 연습 좀 해야겠다.’ ~ ‘그건 아까 했고! 다음 대사!’ → 원문 ‘네가... 날 버린 줄 알았어.’ ~ ‘응.’ → **도망**: 라비엘 ‘이번엔 놓치지 않았네.’ / 루 ‘응. 꽉 잡았더라.’ · **대결**: ‘아까는... 아팠지.’ / ‘그럼 다음엔 살살해. 약속.’ → 교량에서 정한 먹거리(보충, 예: ‘나가면 초코바. 반씩. 큰 쪽은 너.’) → 컵 이야기를 봤으면 한 줄 → ‘라비엘의 손에서 힘이 빠진다.’ ‘…다음 대사. 아직 남았는데.’ → ‘대답은 없다.’
- **상태**: **`ravielState = dead`**, `raviel_dead`, 저장. 라비엘은 쓰러진 자세로 화면에 남음(시신 표현).
- **선택 (기본 선택 없음, 자유 순서)**: 「손을 잡는다」/「이름을 부른다」/「눈을 감겨 준다」/「일어선다」 — 앞의 셋은 각각 한 번, 「일어선다」는 처음부터 고를 수 있음 → ‘루가 일어선다. 다리에 힘이 잘 들어가지 않는다.’
- **확인**: [봇][테스트]

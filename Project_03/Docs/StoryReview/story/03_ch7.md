### S07-3 접수 홀 — 메이린 만남과 보스전
- **맵**: M28 접수 홀
- **등장인물**: 루 (+동행 베넬), 메이린
- **컷신 `c7_meilin_meet`**: 루가 번호표를 두 장 뽑음 →
  - 동행 (GDD 원문 `c7_meilin_v`): 메이린 ‘고객님, 번호표는 한 장씩입니다.’ / 루 ‘뒤에 누나 것도!’ / 메이린 ‘그 누나는 직원이잖아!’ / 베넬 ‘나 직원이었어~?’ / 메이린 ‘아 진짜! 둘 다 여기서 움직이지 마!’
  - 비동행·사망 (`c7_meilin_solo`): 루 ‘한 장은 예비! 잃어버리면 어떡해!’ (+보충 ‘...아 진짜! 여기서 움직이지 마!’)
  - 공통 `c7_meilin_start` (보충): ‘47번 고객님— 호출입니다. 접수는 취소가 안 돼요.’
- **보스전** (`Action/MeilinBoss.cs`): 포획팔이 호출 번호 표적을 잡고 메이린이 돌진. 유지보수 단말(선택지 「호출 번호 47 → 00 · 표적 위치 대기석 → 하역대」/「그대로 둔다」)로 빈 운반 인형 → 메이린 충돌·빈틈. 첫 충돌 때 GDD 원문 ‘그 애 하나를 못 잡아왔단 말이야? ...아니, 너 말고 저 팔!’ / ‘팔도 혼나네.’ 같은 속임수 2회 → 포획팔 정지(‘고객님, 잠시만—아 진짜, 멈춰!’) → 가위·롤러. 셔터·제동 장치·젖은 바닥 연결함도 있음. 일반 공격만으로도 끝남.
- **결과 (컷신 `c7_meilin_retreat`)**: ‘아이.. 난 몰라 몰라...’ / ‘명부는... 다 적어야 하는데.’ → 롤러로 퇴각 → 동행이면 베넬 ‘저 애도 번호표 있었어~’. **메이린 생존**. `c7_meilin_done`, 메이린 숨김(`hide_meilin`), 저장
- **재시도**: 보스 앞 저장 `c7_meilin_before`. 쓰러진 뒤 다시 들어오면 `c7_meilin_met` 이면 곧바로 보스전 재개
- **코드**: `HallMeet`, `MeilinMeet`, `StartMeilin`, `MeilinRetreat`, `FinMeilin` · **확인**: [봇](3경로) [테스트](일반 공격만 / 속임수 반복)

### S07-6 격벽 (컷신 `c7_bulkhead`) — 베넬 분기

- **비동행·사망**: ‘대상 확인.’ / 루 ‘으갹! 지금 오면 어떡해!’ → 혼자 통과 → ‘...휴. 간발이었다.’

- **선택지와 결과**:
  - 빈틈 대화 `v_talk_open`: 「나도 여기서 나가려는 거야.」 / 「왜 나를 찾는 건데?」 / 「너 지금 제정신 아니잖아.」 / 「(말없이 손을 내린다)」 → 신뢰·위협·흥분 수치 변화. 일정 조건(`VenelleMind.WillStop`)이면 **협상 성립**.

### S03-4 관찰 휴게실 벤치 — 동행 여부 결정
- **맵**: M15 관찰 휴게실 (`rest_seat`)
- **진입 조건**: `c3_to_rest` (협상 또는 살림)
- **등장인물**: 루, 베넬
- **실제 대사**: `r_1` 서술 ‘벤치. 둘은 한 칸 떨어져 앉는다.’ → `r_2` 루 ‘...너 누구야?’ 베넬 ‘베넬. ...누나라고 불러도 돼~’ 루 ‘안 불러.’ → `r_3` (방송으로 꼬맹이를 찾으라 했다, 원래 배양실 담당) → `r_4` (승강장 쪽 전기) → 초콜릿이 있으면 `r_choc` 「초콜릿을 건넨다」/「그냥 둔다」 → `r_6` ‘근데 너... 나 안 무서워?’ ‘무서워. 지금도.’ → `r_7` (끊긴 구간은 혼자 못 건넌다) → `r_8` 「출구까지만, 같이 가.」 / 「여기서 쉬어. 난 먼저 갈게.」
- **결과**:
  - 「같이 가」 + 신뢰(`VenelleMind.Trust`) ≥ 3 → `r_join_ok` → **동행** (`venelleState = ally`, `c3_joined`, 동료 생성)
  - 「같이 가」 + 신뢰 < 3 → `r_join_no` ‘...아직은 싫어.’ → **생존·비동행** (`venelleState = apart`)
  - 「여기서 쉬어」 → `r_apart` → **생존·비동행**
- **주의**: GDD 3장의 휴게실 원문(‘린든... 안 무거웠어?’ ‘루야! 무겁긴 했는데…’)은 대사 데이터 `c3_rest` 에 있지만 **코드가 부르지 않는다** (사건 ID `c3_rest` 와 이름만 같고 실제로는 `r_1~r_8` 를 쓴다).
- **비동행 뒤**: 베넬은 M15 벤치에 앉아 있는 인물(`venelle_rest`)로 남는다 — 이 표시를 끄는 플래그(`venelle_bench`)는 이후 어디서도 지우지 않는다 (정적). M15 는 7장 진입 뒤 다시 갈 수 없다.
- **코드**: `StoryEventsQwer.cs` `RestScene` (996), 씬 인물 `Editor/EWRooms.cs` 738
- **확인**: 동행 [봇] / 비동행 [테스트](`Venelle_SpareButGoAlone_ApartStateConsistent`)

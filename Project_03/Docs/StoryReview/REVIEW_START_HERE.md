# 스토리 검토 시작 안내 (다른 대화용)

ELECTRIC WORLD: LAST LIGHT 의 **현재 구현 스토리를 검토**하기 위한 묶음이다. 2026-11-16 시점의 코드를 조사했고, 이 조사에서는 게임 코드, 씬, 대사, 세이브를 하나도 수정하지 않았다. 기준 기획서는 같은 묶음의 `GDD.md` 다.

## 1. 현재 줄거리 (구현 기준, 다섯 줄)
1. 친구(로젤리나)를 잃은 루는 친구 컴퓨터에 접속했다가 시설로 강제 전송된다. 실험체 E-D05-47 로 깨어나 탈출을 시작한다.
2. 3장에서 베넬을 만난다. 베넬은 죽이거나, 살려서 동행하거나, 살려서 따로 남길 수 있다. 4~6장에서는 폐기소의 F와 008, 베넬의 방(아이비와 린든)을 지난다.
3. 7장 수용동에서 사람들을 풀어 주고 메이린을 물리친다. 동행한 베넬은 격벽에서 루를 보내고 죽는다. 8장에서 친구 라비엘과 재회해 대결한 뒤 화해하고, 라비엘이 합류한다.
4. 9장에서 라크리모사를 넘긴 직후 아우렐리우스가 강제 가동을 한다. 이 때문에 지하 대피실(F, 008, 생존자, 비동행 베넬)과 공연장(라크리모사)이 무너진다. 이어 루는 포획됐다가 휴지통에서 복원된다.
5. 10장 최종전에서 아우렐리우스와 메이린이 죽고 라비엘이 다친다. 11장에서 라비엘이 죽고, 루는 남은 전기를 모두 놓는다. 크레딧 뒤에는 응답 없는 게임 창이 뜬 가상 바탕화면이 나온다.

## 2. 구현된 주요 분기
- 베넬: 동행(7장 격벽 사망) / 비동행(9장 대피실 사망) / 3장 처치.
- 폐기소: 과자, 펌프, 거절. 008 에게 과자를 줬는지.
- 라비엘 대결: 도망, 멈춰 세우기. 고백 반응: 손잡기, 옆에 앉기.
- 라크리모사: 설득, 제압.

분기는 대사와 몽타주를 바꾼다. 9장 붕괴 결과와 엔딩은 모든 경로에서 같다. 자세한 표는 [CURRENT_STORY.md](CURRENT_STORY.md) 에 있다.

## 3. 확정된 설정 vs 구현 차이 (요약)
- GDD 와 일치: 큰 줄거리, 사망 순서(베넬 → 대피실·라크리모사 → 아우렐리우스·메이린 → 라비엘 → 루), 대부분의 원문 대사.
- 구현에서 바뀐 것:
  - 오프닝 대사 (A1, A2)
  - 휴게실 대화가 GDD 원문이 아닌 보충 대사다 (A4)
  - 동행에 신뢰 조건이 붙었다 (A7)
  - 붕괴 소식을 통신실이 아닌 서버실에서 본다 (C3)
- 빠진 것:
  - 비동행 베넬의 재합류 제안 (A8)
  - 문서 D02, D04~D09 (B6)
  - 맵 3개 (B7)
  - 컵 후속 장면 (C4)
  - 라비엘 명령 선택 (C6)
  - 아우렐리우스 독백 (D1)
  - 연구원·경비 사망 컷 (D2)

  항목 번호는 [GDD_DIFFERENCES.md](GDD_DIFFERENCES.md) 기준이다.

## 4. 먼저 검토할 모순·위험
1. **린든 이름 첫 언급 위치**: GDD 안에서 휴게실과 세탁실이 서로 다르다. 구현에서는 동행 말풍선이 세탁실보다 먼저 나올 수도 있다 (A5, A6, 미확인).
2. **휴게실 대화 정본**: GDD 원문이 데이터에는 있지만 쓰이지 않는다 (A4).
3. **엔딩 뒤 이어하기**: 마지막 장면이 다시 시작되지 않을 가능성이 있다 (D5, 미확인).
4. **검수 도구로 지난 맵에 가면 죽은 F·008 이 서 있을 가능성** (B4, E4, 미확인). 정상 진행에는 영향이 없다.
5. **폐기소·라크리모사 결과가 사망 장면에 반영되지 않는다** (B5, C7). GDD 9.2 와의 관계를 결정해야 한다.

## 6. 사용자가 아직 정하지 않은 것
아래는 조사자가 대신 정하지 않았다. 각 항목의 ‘사용자 결정 필요’ 칸을 보라.
- 오프닝, 연구원, 휴게실 대사 중 어느 쪽이 정본인가
- 린든 첫 언급 위치
- 베넬 동행 신뢰 조건을 유지할지, 비동행 베넬의 재합류 장면을 넣을지
- 3장 처치와 11장 라비엘의 시신 표현
- 폐기소·라크리모사 결과에 따라 사망 장면을 다르게 할지
- 붕괴 소식을 보는 장소
- 빠진 문서·맵·장면(컵, 독백, 사망 컷)을 넣을지
- 코드에만 있는 사건과 대사(UNWIRED)를 처리할지
- 검수 프리셋을 실제 진행 값과 맞출지

### D16 전이 장치 정비도 *(보충)*

전이 장치 구조: 외피 / 호위 장치 / 축전 모듈 둘 / 냉각관 / 전이 결합부.  
  
- 호위 장치는 강자성 부품. 정비용 전자석으로 고정 가능.  
- 축전 모듈 과부하 시 결합부 보호가 풀림.  
- 냉각 밸브를 닫으면 다음 충전이 과열로 중단.  
- 결합부는 대출력으로만 분리 가능.

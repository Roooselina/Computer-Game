# GDD 와 실제 구현의 차이 (2026-11-16 조사)

- 기준 문서는 `GDD.md`, 비교 대상은 현재 실행 경로다. 사건 코드 `Assets/Game/Scripts/Runtime/Story/*.cs`, 방 정의 `Assets/Game/Scripts/Editor/EWRooms*.cs`, 대사 `Assets/Game/Data/Dialogue/dialogue_ko.json` 을 보았다.
- 이번 조사에서는 **아무것도 고치지 않았다.**
- **근거 표시**
  - [봇]: 자동 진행 봇이 지나간 기록이 있다.
  - [테스트]: 자동 테스트가 있다.
  - [정적]: 코드만 읽었다.
  - **미확인**: 실제 동작을 확인하지 못했다.
- 원인은 코드에서 바로 보이는 것만 적었다. 추정한 원인은 적지 않았다.
- **분류 7종**
  - ① 스토리 변경
  - ② 누락 장면
  - ③ 사망 플래그 누락
  - ④ 사망 후 화면 잔존 객체
  - ⑤ 사망 후 대사 조건 오류
  - ⑥ 저장·불러오기 오류
  - ⑦ 검수 프리셋 전용 문제

  목록에 맞지 않는 항목은 가장 가까운 분류에 넣고 비고를 달았다.

# 인물별 타임라인 — 현재 구현 기준 (2026-11-16 조사)

조사 방법: 실제 실행 경로(사건 코드 `Assets/Game/Scripts/Runtime/Story/*.cs`, 방 정의 `Assets/Game/Scripts/Editor/EWRooms*.cs`, 생성 씬 보고서 `Docs/Generated/built_layout_report.json`, 대사 `Assets/Game/Data/Dialogue/dialogue_ko.json`) 정적 분석 + 2026-11-15/16 자동 진행 봇·자동 테스트 기록.
사람이 직접 플레이해 확인한 내용은 없다. **[봇]** 봇 통과 · **[테스트]** 자동 테스트 · **[정적]** 코드만 · **미확인** 확인하지 못함.
장면 ID(S03-3 등)는 [CURRENT_STORY.md](CURRENT_STORY.md) 기준.

공통 사실:
- 동료(따라오는 인물)는 **한 번에 한 명**: 베넬(동행일 때 3장~7장 격벽) → 라비엘(8장 방 대화 뒤 ~ 10장 대면, 부상 상태로 10장 붕괴 연결로까지). 동료 생성 조건은 저장 상태(`Game.OnMapReady`): 베넬 `venelleState == ally && venelle.state != dead`, 라비엘 `ravielState == ally 또는 injured` (동료 금지 맵 제외).
- **동료의 전투 지원은 일반 전투에 구현되어 있지 않다** (`Field/Companion.cs` 는 따라오기만 함). 장면 연출 속 지원만 있다: 베넬 M23 산성 바닥판, 라비엘 최종전 엄호막.
- 7장 연결문 이후 1~6장 맵(M24 이전)은 정상 진행으로 다시 갈 수 없다. 그 맵에 남은 인물 표시는 **검수 도구 이동으로만** 보인다.

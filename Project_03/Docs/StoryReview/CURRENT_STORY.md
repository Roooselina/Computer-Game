# 현재 구현 스토리 — 목차 (2026-11-16 조사)

이 문서는 새 게임부터 엔딩까지 장면 순서대로 정리한 목차다. 지금 실행되는 코드와 데이터를 기준으로 했고, 예전 보고서는 기준으로 삼지 않았다.

**확인 표시**

| 표시 | 뜻 |
|---|---|
| **[봇]** | 자동 진행 봇이 지나간 장면 (2026-11-15/16 기록 `Docs/Media/ch7_11_2026-11-16/`) |
| **[테스트]** | 자동 테스트(EditMode 47 / PlayMode 54)가 직접 확인 |
| **[정적]** | 코드·데이터만 읽음 |
| **미확인** | 확인하지 못함 |

**사람이 직접 플레이해 확인한 장면은 없다.**

각 장면 항목에는 장면 ID, 맵, 진입 조건, 등장인물, 사건, 실제 대사·선택지, 결과, 상태 변화, 다음 장면, 관련 코드를 적었다. 대사 전문은 각 장의 `appendix/` 덤프에 있다. 덤프는 사건 코드가 실제로 부르는 대사 ID를 따라가 자동으로 뽑았다(`added` 표시는 GDD에 없는 보충 대사).

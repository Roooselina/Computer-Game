# 컷신 순서와 건너뛰기 종료 상태 (2026-11-15)

모든 컷신은 `Cutscene.Play(g, id, 본문, 완료처리)` 로 실행한다. 오른쪽 아래에 `Enter · 연출 건너뛰기`(실제 키 이름)가 보이고, **Enter 한 번**으로 건너뛴다. 선택지가 열려 있는 동안에는 건너뛰기를 받지 않는다(`Game.ChoiceOpen`).
건너뛰든 끝까지 보든 **완료처리(Fin…)** 가 같은 상태를 적용하고, 공통 정리가 다음을 되돌린다:
대화창·스탠딩·레터박스 닫기, 루의 연출 조종·애니메이션 덮어쓰기·고정(Frozen)·모습 크기/위치/회전 복구, 카메라 추적 복귀(확대 1배, 건너뛰면 즉시 맞춤), 히트스톱 해제(시간 배율 1), 중간 페이드 해제, 입력 상태 Cutscene 해제, 필드 입력 차단 해제.
연출 시간 기록: `Temp/EWBridge/cuts.txt` (전체 / 대화창이 열린 시간 / 자동 연출 = 나머지).

- 베넬 잡기 대화 `VenelleGrabTalk` → 던지기, 숨 고르기·재혼합 대화 `VenelleTalk`, 쓰러진 뒤 `VenelleDownedChoice`(죽인다/죽이지 않는다), 협상·살림 뒤 `VenelleEnd2`(쓰러짐 개그 → 짧은 부축 → 컷), 휴게실 `RestScene`(초콜릿·임시 동행 선택).

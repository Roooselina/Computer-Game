# 연출 설계서 — 오프닝 ~ 첫 전투, 주요 장면

구현 위치: `Assets/Game/Scripts/Runtime/Story/StoryEvents.cs` (장면 코드), `Story/Cutscene.cs` (실행기),
대사 `Assets/Game/Data/Dialogue/dialogue_ko.json`, 장소 배치 `Assets/Game/Scripts/Editor/EWRooms.cs`.
실제 재생 기록: `Docs/Media/opening_to_first_battle.webp` (자동 입력으로 실제 시간 재생, 4fps 녹화).

## 0. 공통 규칙

| 항목 | 방식 |
|---|---|
| 실행기 | `Cutscene.Play(id, 본문, 완료 처리)` — 본문 코루틴을 한 단계씩 직접 실행한다 (Timeline 미사용: 기존 이벤트 코루틴과 같은 방식이라 유지보수가 쉽고, 대사·플래그·장치 상태와 바로 연결됨) |
| 입력 | 컷신 동안 필드 입력 차단(`Block("cutscene")`), 끝나면 이동 입력·카메라 추적 복구 |
| 건너뛰기 | **Esc(패드 Start/Select)를 1초 누르고 있기** — 오른쪽 위에 게이지가 찬다. 짧게 누르면 아무 일 없음(실수 방지). 컷신 전부터 누르고 있던 Esc 는 무시 |
| 건너뛴 뒤 | 본문만 멈추고 **완료 처리(finalize)** 가 장면 끝 상태를 적용한다: 플래그, 인물 위치·자세, 문·장치 그림, 환경음, 카메라. 끝까지 봐도 같은 완료 처리가 실행된다(중복 실행 안전) |
| 중복 방지 | 장면마다 완료 플래그(`op_village_done` 등). 다시 들어와도 다시 나오지 않고 연구원·효과가 다시 생기지 않는다 |
| 불러오기 | 플래그로 장면 상태 복원: `FrameSet`(문·통·콘솔 그림), `FlagVisual`(조명·어둠·파편 표시, 통 벽 충돌), `ActorSpawn.downFlag`(쓰러진 연구원 위치) |
| 렉 느낌 | `Cutscene.HitStop` — `Time.timeScale` 을 잠깐 0. 메인 스레드는 멈추지 않으며 UI·소리는 계속된다 |
| 흔들림·번쩍임 | 설정 메뉴의 화면 흔들림·번쩍임 배율(0 = 끔)을 곱한다. 지속적인 강한 점멸 없음(최대 0.45초 한 번) |
| 대사 | 자동으로 넘기지 않는다. 결정 키: 출력 중이면 현재 페이지 완성, 다음 입력부터 다음 페이지. 대화창이 열린 순간의 같은 입력은 무시 |
| 스탠딩 | 대사 줄에 표정(`e`)이 있는 줄만 표시. 마을 장면은 얼굴을 보여 주지 않으므로 없음 |
| 카메라 기준 | 대화창(아래 24%)이 발을 가리지 않도록 인물 발을 화면 아래 약 33~40% 에 둔다 (`발 + 1.9 유닛` 구도) |

## 첫 탈출 구역 (`C02`)

| 단계 | 내용 |
|---|---|
| 관찰 (`c1_escape_view`, 짧은 컷신) | 카메라가 막힌 잔해 → 멀리 순찰 경비 → 루로 돌아옴. 루: ‘길이 무너졌네... 위로 돌아가든지, 밑으로 기어가든지.’ |
| 짧은 행동 | 위: 1칸 발판 계단 → 잔해 위 통로(과자·회복 붕대, 깨진 관찰창 너머 휴식실 불빛) → 사다리/뛰어내림. 아래: 점검 도랑(1칸 턱 두 번) |
| 전투 | 합류 지점의 순찰 경비(방어 자세). 바닥 노출 전선(빛·불꽃으로 눈에 띔)을 조사해 두면 '기물'. 전투 카메라가 전선까지 화면에 넣는다 |
| 반응·보상 | 경험치·드롭 → 셔터(지름길)가 열리는 짧은 컷신 → 루: ‘열렸다...! 저 안은 조용해 보여.’ |
| 다음 목표 | 배터리 조명이 켜진 예비 전원실(침대: 회복·저장) → 오른쪽 출구 |

## 전투 (공통)

| 단계 | 연출 |
|---|---|
| 진입 | 같은 장소에서 카메라 2배(정수 배율) 확대, 짧은 흰 번쩍임, 전투 음악. 적이 옆에서 밀려 들어옴 |
| 명령 | 화면 아래 명령 띠(대화창 자리) + 그 위 진행 메시지. 대상 선택 시 머리 위 ▼, 예상 피해·방어 상태 표시 |
| 톡! | 반 발짝 다가가 검지 튕김 → 스파크 → 복귀 |
| 스파크 샷 | 겨눔 → 전기탄 2발이 날아감 |
| 아크 채찍 | 다가가 팔 휘두름 → 호 |
| 번개 발차기 | 미끄러져 들어가 차기(강타: 긴 히트스톱·큰 밀려남) → 휘청 → 복귀 |
| 기물 | 루가 기물 쪽을 보고 겨눔 → 손끝 → 기물로 전류 → 기물이 번쩍 → 땅을 타고 적에게. 방어 자세가 무너진 적은 **기울어져 떨림**([휘청]) |
| 피격 | 번쩍임 → 히트스톱 0.05초(치명·강타 0.09) → 밀려남 → 피격 동작 → 숫자 → 복귀. 전기(지지직)/물리(쿵) 소리 구분 |
| 강공격 | 한 턴 전 붉은 기운 + 경고 표시, 실제 공격 때 긴 준비 + 흔들림 |
| 보스(베넬) | 입장 컷신: 약품 통 사이 높은 단의 실루엣 → 뛰어내림 → 대사. 긴장 음악. **베넬 보스 전용 원화 없음** (임시 그림, 일반 크기) |
| 빠르기 | 설정의 '전투 연출 빠르기'로 동작 대기 시간을 최대 절반으로 |

## 장소 전환

장 번호 전체 화면 카드 없음. 맵 이동은 0.25초 짧은 암전 + 환경음 교차 페이드. 오프닝 장면 사이만 연출로 이어진다.

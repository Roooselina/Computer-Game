# 컷신 흐름 — 아트·플레이 개선판

기존 최단 연출 기준은 폐기했다. 대사 타이핑(기본 한글 23자/초), 자동 연출, 페이드, 효과 수명을 각각 조정한다. 전체 timeScale을 낮추는 방식은 사용하지 않는다.

|---|---|---|
| 마을 | 바라봄 → 두 대사 → 몇 걸음 → 돌아봄 → “안돼...” → 절망 자세·여운 → 짧은 길 → 집 | P02 진입 |

Enter 한 번으로 Cutscene.Play 구간을 건너뛴다. 선택지는 수동 확정한다. 공통 종료 처리는 대사·스탠딩·레터박스·섬광·신호 왜곡·View 위치/크기/회전·조종·고정·카메라·히트스톱·입력 상태를 복구한다. 안내서와 대화가 닫힐 때 누르던 키는 놓기 전까지 다시 쓰지 않는다.

자동 읽기 지연 0.9~1.0초를 사용한 최종 촬영 측정: 마을 19.4초, 집 약 22초, 단말 도착 2.8초, 포획 6.1초, 통 35.1초, 베넬 등장 26.8초. 사람의 실제 읽기 시간이나 재미 평가가 아니다. 최종 연속 프레임과 움직이는 WebP는 [실행 보고](ART_PLAY_OVERHAUL_REPORT.md)에 연결했다.

- 미구매 유료 에셋 2종은 쓰지 않았다. 새로 산 것 없음. 받은 외부 자료는 Pretendard(공식 저장소 릴리스, OFL)뿐.

## 4. 남은 문제
1. **분량**: 첫 조작→베넬이 봇 기준 2분 29초. 사람 실측 후 C03~C05 감시 구역을 넓히거나 구역을 추가해야 할 가능성이 크다 (빈 복도로 늘리지 않을 것).
2. 사람이 직접 한 플레이·재미·긴장감·반응 속도 검증 없음. 수치는 초기값.
3. 게임패드 실기 확인 없음. 키 변경 화면은 자동 테스트하지 않았다 (PlayerPrefs 를 바꾸므로).
4. 4.2 표의 나머지 기술(아크 채찍·번개 발차기·연쇄 전류 등)은 실시간 버전 미구현. 베넬 동행 중 행동(회복약 등)도 실시간 미구현 — 지금은 따라오기·말풍선만.
5. 동행 첫 대사를 임시 협력으로 바꿨지만, 친밀한 잡담 말풍선을 신뢰 단계로 막는 규칙은 아직 넣지 않았다.
6. 경비가 엄폐 상자를 깊이로 지나가는 처리는 그림상 어색할 수 있다 (최종 아트에서 상자 배치·경로로 다듬기).
7. 빌드 창 크기에 따라 타이틀 화면 위쪽에 빈 띠가 보인다 (이전부터 있던 레이아웃 문제, 이번에 고치지 않음).
8. 녹화 영상은 베넬 만남의 루 대사 두 줄에 스탠딩이 남아 있던 상태로 찍었다 (녹화 뒤 그 두 줄의 스탠딩을 뺐다).
9. 이번 작업 중 화면 확인용으로 맵 씬을 바로 실행했을 때 체크포인트 저장이 **실제 저장 파일을 덮어썼다**. 원래 저장(v2, M15 시연 끝, 37분)은 변환 코드가 보존해 둔 사본으로 되돌렸고, 덮어쓴 개발용 저장은 `Backups/2026-11-14_dev_overwritten_saves/` 로 옮겼다. 이후 에디터에서 맵 씬을 바로 실행하면 `Temp/EWDevSave` 에만 저장하도록 고쳤다.
10. 미구현 그대로: 베넬 처치·그냥 지나침 분기, 11번 기록 창고, 2장 이후 동료 실시간 행동.

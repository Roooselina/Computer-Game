# 입력 안내 — 아트·플레이 개선판

기본 배치는 `GameInput`의 `ew.key3`에 저장된다. 이전 J/QWER 배치는 새 기본 키로 이행하며 사용자 저장 진행은 유지한다.

| 장소·동작 | 기본 키 |
|---|---|
| 필드 좌우 이동 | A / D 또는 ← / → |
| 조사·열기·대화 / 대상이 없으면 점프 | Space |
| 사다리 위·아래 | W / S |
| 사다리에서 옆으로 이탈 | A / D |
| 지상 웅크리기·전경 엄폐 | S |
| 대시 | AA / DD (같은 이동 키를 0.25초 안에 두 번) |
| 기본 전기 공격 | Q |
| 기계 간섭 | E |
| 외부 전력을 연결한 강한 방전 | R |
| 전원선 이동 | F |
| 취소·메뉴 | Esc |
| 컷신 건너뛰기 | Enter |
| 컴퓨터 내부 자유 이동 | WASD (무중력, 점프 없음) |
| 대화 타이핑 완료 / 다음 문장 | Space 첫 입력 / 다음 입력 |
| 선택지 이동·확정 | 방향키 / Space |

상호작용은 가장 적절한 대상 하나만 고른다. 소비된 Space는 같은 프레임의 점프로 전달되지 않는다. 대화·문서가 닫힐 때 누르던 키는 놓은 뒤 다시 누른다. J는 기본 바인딩에 없다. 스킬 순환은 없다.

설정에서 바꾼 키는 HUD와 안내서에 반영된다. 안내서는 컴퓨터 아이콘 또는 Esc 메뉴에서 다시 열 수 있다. 인터넷과 안내서를 모두 확인한 뒤 안내서를 닫으면 포획이 시작된다.

대시: 같은 방향을 눌렀다 놓고 0.25초 안에 다시 누른다. 첫 입력부터 걷고, 두 번째에 해당 방향으로 한 번 대시한다. 길게 누르기·키 반복·AD/DA는 발동하지 않는다. 쿨다운 입력은 예약하지 않는다. 대화·문서·메뉴·컷신·사다리 및 이탈 직후·단말에서는 필드 대시를 받지 않는다. 상태·씬·재시도·포커스 전환 때 기록을 비운다. 이동 키 변경 시 같은 키 두 번으로 동작하며 HUD/안내/설정에 표시한다. 예전 저장 Shift 대시 바인딩은 읽지 않는다. 선택적인 게임패드 오른쪽 트리거는 유지한다. 거리 2.4, 지속 0.15초. 재사용 대기는 **대시가 끝난 뒤부터 0.15초** 한 번만 센다 (시작 시점 쿨다운과 겹치는 이중 대기 없음). 대기 중에 누른 **첫 번째** 탭은 기록해 두고, 두 번째 탭 순간 쓸 수 있으면 바로 대시한다 — 두 번째 탭을 저장했다가 늦게 발동하지는 않는다. 무적은 이동과 따로: 대시 시간(0.15초) 안에서만, 그리고 0.55초에 한 번만 다시 붙는다 (연속 대시로 끝없는 무적 불가). 대시 뒤 이동 잠금 없음. 별도 전하 비용은 없다. `action_tuning.json`의 `player.dodgeTime / dodgeDistance / dodgeInvuln / dashCooldownFromEnd / dashInvulnRearm / doubleTapWindow` 로 조정. (2026-11-15 측정, 같은 연타 리듬의 실제 플레이어: 평균 재사용 간격 DD 0.75→0.30~0.40초, AA 0.90→0.30초, AA 직후 DD 0.65→0.37초, 연타 중 무적 비율 35%→20~31% — `Tests/PlayMode/DashTimingTests.cs`)

## 7~11장·엔딩·검수 도구 (2026-11-15 추가)

| 상황 | 조작 |
|---|---|
| 보스 구역 기물 (유지보수 단말·제동 장치·셔터·믹서·전자석·냉각 밸브) | 가까이서 Space(조사) → 선택지는 A/D, Space 결정. 메뉴가 열려 있는 동안 보스의 공격·타이머는 멈춘다 |
| 바닥 연결함·축전 모듈 | E(외부 전력 방전) — 화면에 배전함이 보일 때. 일반 공격으로도 부술 수 있다 |
| 라크리모사에게 말 걸기 | 보호 정지·멈춤 중 가까이서 Space |
| 한계 방출 (최종전) | 결합부가 드러나면 결합부 앞에서 Space. 전하가 가득해야 한다 (자연 충전 또는 **전하 모으기**). 시간 제한 없음 |
| 전하 모으기 | 최종전 시작 때 빈 칸(없으면 전원선 칸에 임시)에 들어간다. 누르면 0.6초 멈췄다가 전하 +2. 전투 뒤 원래 칸으로 되돌림 |
| 포획 단말·휴지통 안 | WASD 무중력 이동. 기술은 봉인 (‘여기서 터뜨리면 나도 길 잃어!’) |
| 휴지통 목록 창 | W/S(↑/↓) 항목 이동, A/D 아래 버튼 이동, Space 결정, Esc 닫기. 버튼: 정렬(삭제한 날짜) / 선택한 항목 복원 / 내부 확인 / 닫기 |
| 엔딩 가상 바탕화면 | A/D 로 종료·대기 (기본 선택 없음), Space 결정, 마우스 클릭 가능. 그 뒤 게임 자체 메뉴로 타이틀/게임 종료 |
| **Esc → 검수 도구** | 현재 맵·장·체크포인트 표시 / 정상 진행의 다음 맵(후보와 조건) / 이전 방문 맵 / 전체 맵(장별) / 주요 사건 프리셋(베넬 분기 선택, 바뀌는 내용 확인 후 적용) / 현재 맵 다시 시작 / 검수 슬롯 저장·이어하기 / 검수 시작 전 상태로 복귀 |

검수 이동을 처음 하면 ‘검수 모드’가 켜지고 화면 오른쪽 위에 작게 ‘검수 모드 · 목적지’가 보인다. 이때부터 모든 저장은 일반 저장 폴더 아래 `review/` 에만 쓰인다.
타이틀로 돌아가거나 ‘검수 시작 전 상태로 복귀’하면 일반 저장 위치로 돌아간다. 일반 빌드에서 이 메뉴를 숨기려면 `Resources/EW/GameConfig` 의 `reviewToolsInRelease` 를 끈다.

## 4. 감시
### 경비 (Guard: 순찰 경비·포획 드론·운반 로봇)
상태: 순찰 → 의심(멈춰서 바라봄, ‘?’) → 확인(마지막으로 본 곳으로 감) → 추적(‘!’, 보이는 동안만 위치 갱신) → 마지막 발견 위치 수색(좌우를 살핌) → 순찰 복귀.
- 시야: 눈높이에서 앞쪽 원뿔 (경비 6u·24°, 드론 5u·30° 아래 방향). 벽·상자 등 고체가 시야선을 막는다. 위 통로는 경비 시야 밖.
- 의심 게이지: 보일 때 초당 0.85×(가까우면 2배, 멀면 0.6배)×(웅크림 0.6)×(경보 1.25)×(이야기 0.75). 1 이 되면 발견. 안 보이면 0.6초 뒤 초당 0.45씩 감소.
- 등 뒤에 바짝 붙으면 기척으로 의심이 천천히 오른다 (엄폐물 옆에 웅크리면 없음).
- 소리: 반경 안이면 0.55초 고개를 돌린 뒤 그 위치를 확인하러 간다. 발소리는 의심만 조금.
- CCTV·다른 경비의 신고는 ‘그 위치’만 알려 준다. 벽 너머를 보지 않고 루 위치를 계속 알지 못한다.
- 공격: 준비 0.75초(몸이 깜빡이고 제압봉 소리) → 판정 0.16초 → 회복 0.8초, 재사용 1.3초. 드론은 0.9초 준비 후 아래로 전류.
- 경직 잠금 방지: 3초 안에 2번 경직되면 1.6초 동안 경직 면역.
- 쓰러뜨리면 ‘일시 무력화’: 28초 뒤 다시 켜져 수색부터 시작. 죽이지 않는다.
- 낮은 엄폐 상자는 경비가 지나갈 수 있다 (상자 앞뒤 깊이로 지나감 — 경비가 상자 사이에 갇히지 않게). 루는 1칸 상자를 점프로 넘는다.

### CCTV
- 두 각도 사이를 초당 16°로 돌고 끝에서 1.4초 멈춤. 범위 7.5u, 반각 17°.
- 시야 표시: 감지와 같은 광선 계산(`Sight.Cast`)으로 벽·상자에 잘린 부채꼴. 평소 옅은 청록, 의심 노랑, 발견 빨강(맥동). 테두리선도 같은 색. **표시와 판정 일치율 97% 이상** (PlayMode 테스트, 광선 사이 경계 제외).
- 보이면 렌즈가 루를 따라가며 게이지 상승(초당 0.6×거리 보정). 다 차면 근처 14u 경비에게 위치 신고, 보이는 동안 3초마다 재신고.
- 간섭: 렌즈가 꺼지고 고개가 처짐 8초. 전력 끌어오기: 부서짐(영구, 저장).

### 엄폐 (2026-11-15 개정: 두 종류로 분리)
- **A. 올라서는 고체 상자 (`Cover`, `S_CrateSolid`):** 통과할 수 없고 발판이 된다. 윗면 밝은 띠 + 노랑 사선 무늬로 '올라설 수 있는 물건'임을 보인다. 고체라 시야선도 막는다(낮은 상자 뒤에 웅크리면 옆에서 보는 경비에게는 가려진다).
- **B. 뒤에 숨는 전경 엄폐물 (`HideSpot`, `S_HideRack`·`S_HideSacks`):** 트리거라 루가 뒤쪽 영역으로 들어간다. 루보다 앞(정렬 20)에 그린다. 영역 안에서 S 로 웅크리면 **숨음**: `Sight.SeePlayer` 가 0 — CCTV·경비 판정에서 실제로 빠진다. 숨은 동안 엄폐물 앞에 옅은 청색 윤곽(같은 프레임)으로 루 위치가 보이고, 엄폐물이 살짝 비친다. 영역에 들어서면 'S · 숨기' 프롬프트.
- 숨은 동안 시야에 없으므로 의심 게이지가 줄어든다. **적의 기억은 지우지 않는다:** 추적 중이던 경비는 마지막 발견 위치를 수색하고, **보는 앞에서 숨었다면(숨는 순간 0.35초 안에 시야 안이었다면)** 바로 옆(1.15u)까지 온 경비에게 들킨다 → 먼저 시야를 끊고 숨어야 한다.
- 엄폐 영역 밖으로 나가거나, 일어서거나, 공격(톡!·샷 0.8초, 방전 1초)하면 바로 노출. 약한 간섭(W)은 숨은 채 쓸 수 있다.
- 원인 기록: 개편 전에는 모든 상자가 고체라 겹칠 수 없었고, 천장 CCTV 는 위에서 내려다보므로 상자 '옆'에 웅크린 루를 그대로 봤다(시야선이 상자를 지나지 않음). 상자 충돌체를 없애지 않고 역할을 나눠 해결했다.

### 발각의 결과 (2026-11-15)
- CCTV 게이지가 차면 14u 안 경비를 **사냥 모드**로 부른다: 추적 속도로 신고 위치에 와서, 루를 보면 의심이 3배 빨리 차 곧 추적·공격. 못 보면 그 자리 수색 후 복귀.
- 부를 경비가 없으면 출입 지점(`ReinforcePoint`)에서 **지원 드론**: 맵당 최대 2대, 한 번에 1대. 화면 밖 지점을 우선하고, 화면 안 지점뿐이면 1.2초 경고 뒤 등장. 지점이 없는 맵은 화면 가장자리 바깥. 등장 0.6초 뒤 이동 시작, 수색을 마치면 화면 밖으로 날아가 사라진다. HUD: '! 경비 호출 — 시야를 끊어!' / '지원 드론이 온다'.
- 벗어나는 법: 회피(Shift)·Q 경직·W 정지·시야 단절·전경 엄폐.

## 5. 시설 경보 (2026-11-15 개정)
- 실험 통 탈출 직후(`FinTank2`) `lab_alarm` 이 켜지고, 베넬이 나타나 전투가 시작될 때(`StartVenelleFight2`) 꺼진다. 정체 깨달음 사건은 더 이상 경보 조건이 아니다.

## 6. 실패와 재시도
- 안정도 0 → 0.7초 쓰러짐(시간 0.35배) → 페이드 → **가장 최근 구간 시작점**(맵 입구·구간 체크포인트 영역)에서 재시도. 안정도 최대, 전하 최소 2.
- 구간 시작 이후 쓴 아이템·얻은 아이템·장치·전원 사용 횟수·경험치는 시작점 상태로, 대사/말풍선 출력 이력은 유지 (`GameState.RestoreForRetry`). 오프닝·도입 컷신은 완료 플래그로 다시 나오지 않는다.

- 세 번 공격하면 재혼합. 패턴은 한 번에 하나.
- **잡기:** 베넬 손(발 기준 +0.41, +1.44) = 루 목덜미(발 기준 0.97). 루는 'Lifted'(발이 0.47u 떠서 버둥거림), 베넬이 루보다 앞에 그려져 손이 목덜미에 보인다. 대화 중 모든 위험 정지. 처음은 긴 대사, 다시 잡히면 짧은 대사. 대화가 끝나면 앞으로 집어 던짐(포물선 0.55초, 회전) → 착지 피해 1회 → 쓰러짐 0.35초 → 일어남 0.3초 → 보호 1.3초.
- **협상(`VenelleMind`):** 위협(시작 5)·신뢰(0)·흥분(4). 말 걸 기회 = 숨 고르기·재혼합·잡기.

- **쓰러짐(`Downed`):** 체력 0 → 죽지 않고 무릎 꿇음. 남은 약병·웅덩이·표식 즉시 제거. 1.7u 안에서 J '다가가기' → '죽인다 / 죽이지 않는다'(기본 선택 없음). 분기는 `Docs/VENELLE_BRANCHES.md`.

## 8. 남은 조정 과제
- 모든 수치는 자동 재생(봇) 기준으로만 확인했다. 사람의 반응 속도·긴장감·재미는 아직 측정하지 않았다.
- 시간 측정은 `Docs/IMPLEMENTATION_STATUS.md` §시간. 사람 플레이 측정 전에는 구간 길이를 판단하지 않는다.


## 4~6장 장치·적 (2026-11-15)
- **컨베이어** (`Devices/Conveyor.cs`): 전원선 모터가 켜져 있을 때만 돈다. 윗면의 루(이동 속도에 더함)·경비(벽·끝에서 멈춤)를 민다. 제어반(`BeltControl`)의 정상 조작으로 방향을 바꾼다 (저장됨). 정전되면 벨트·상자 그림도 멈춘다.
- **전원선 제어함** (`GridBox`): 외부 전력 방전으로 과부하 → 같은 선(`hall_grid`)의 벨트 모터·PC·출구 문이 함께 정전. 배터리가 보이는 PC 는 계속 켜짐. '전원 복구' 버튼 또는 문 위 환기 통로로 진행. 전기를 썼다고 암호·파일 권한이 바뀌지 않는다.
- **물 펌프** (`PumpRig`/`PumpControl`): 수위(0~100)·차단기·이음쇠 상태가 그림·램프·상태판에 그대로. 물 위로 전원 → 차단기가 튐, 물속 이음쇠 → 손이 닿지 않음, 전원 켠 채 이음쇠 → 불꽃만 튀고 손을 뗌, 깨진 채 가동 → 헛돎. 어떤 조작도 되돌릴 수 있고 부품을 잃지 않는다.
- **겁먹은 생존자** (`Scavenger`, 4장 교섭 실패 시): 같은 필드의 실시간 충돌. 경계 → 접근 → 0.8초 예고(깜빡임) → 휘두르기(6, 이야기 난이도 ×0.65) → 물러남, 멀리서는 그림자 예고가 있는 고철 던지기. 루의 전기에 맞으면 '겁'(3)이 줄고 0 이면 파이프를 놓고 주저앉는다(진정, 다시 싸우지 않음). 죽거나 쓰러지는 그림 없음. 셋 모두 진정 → F 가 말리고 대화 → 통로 열림.
- **경비 금지 구역** (`Guard.NoGo`): 산성 약품이 고인 바닥 — 경비는 들어가지 않는다, 루는 지나갈 수 있다. 맵이 바뀌면 지운다.
- **수직 배선통로 추격**: 1층 진입 → 뒤 문에서 경비 등장(추적). 경비는 사다리를 타지 못하므로 층을 올라가며 따돌린다. 2층: 동행이면 베넬이 금속 바닥판에 약품(금지 구역) → 루가 연결함에 전류 → 바닥판 위 경비 일시 무력화. 비동행이면 벨트가 경비를 문 쪽으로 되밀고 셔터 패널로 길을 막는다. 3층: 드론, 전원선으로 꼭대기 턱. 쓰러지면 1층 시작점에서 다시 (추격 전 상태).

# REBUILD_PLAN - Notes 기준 장면 순서와 기존 맵 대응 (초안)

작성: 2026-11-24. 기준: NOTES_STORY.md (유일한 스토리 기준), 확정 결정은 REBUILD_PROMPT.md 3장.
상태: 초안. Unity 컴파일/실행 확인 없이 문서만으로 작성했다. Claude Code가 단계 1에서 코드와 대조해 확정한다.
대응 열의 기존 맵은 world_layout.json의 ID이고, "재사용"은 맵 구조를 살린다는 뜻이다. 실제 판단은 코드를 읽고 한다.

## 1. 확정된 결정 (이번 대화)

- 7장 메이린: 베넬 처치 루트여도 베넬과 메이린은 같이 죽는다. 퇴각/생존 분기는 만들지 않는다.
- 최종 보스: 1단계(검은 손 압사, 바닥 전기, 탄막) + UI 간섭 단계(이동키 변경, 스킬창 삭제, 화면 비율 축소).
- 주의: Notes의 최종전에는 두 단계 사이에 "세 아이들(베넬, 메이린, 라크리모사)의 능력을 쓰는 단계"가 있다. 위 결정으로 이 전투 단계는 만들지 않는다.
  Notes의 해당 대사(환영 등장, 루가 누나를 부름)는 전투 없는 연출로 남길지 개발자에게 단계 1에서 확인한다. 10장 환영 페이즈 없음 결정과 같이 판단한다.
- 아직 미정: 한계 방출 3회의 위치, 챕터 압축 분량(5~6장, 건물 폐쇄 구간).

## 5. 떡밥 설계 (회수 위치)

- 베넬이 루를 린든으로 착각: B~L, L 이후 해제.
- 베넬 옷 2벌, 편지, 사진, 초코바 10개: M에서 회수, 최종 장면의 베넬 환영 대사로 이어질 수 있음(환영 단계 삭제 결정과 충돌하므로 확인 필요).
- 초콜릿: D에서 시작, M, R의 초코바로 반복.
- 실리콘 스프레이: L에서 획득, 메이린의 롤러 패턴 O에서 사용처.
- 라비엘이 루를 부른 이유: R에서 회수.
- 로젤리나의 전쟁 언급: R. 구현 여부는 기존 코드의 해당 사건을 확인.

# ELECTRIC WORLD: LAST LIGHT

Unity 2D side-view real-time stealth action game (URP, Unity 6000.6.x).

## Status
- Mid-development snapshot, pushed before a full story/map/choice rebuild.
- The rebuild source of truth is Docs/Redesign/NOTES_STORY.md.
- Rebuild instructions for Claude Code: Docs/Redesign/REBUILD_PROMPT.md.
- Legacy docs (GDD.md and older Docs) describe an earlier design and are not authoritative.

## Layout
- Assets/Game: game code (asmdef modules), data (dialogue JSON, world layout), scenes
- Assets/ThirdParty: imported third-party assets
- Docs: implementation status, design notes, Redesign folder
- Tools: helper scripts

## Not included in the repository
- Library, Logs, Builds, Backups, UserSettings (regenerated by Unity or local only)
- Large source document (story reference docx)

## Open
Open the folder with Unity Hub using Unity 6000.6.x. The first import regenerates Library.
